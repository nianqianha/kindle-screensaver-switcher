# Kindle 换屏保工具 · 使用说明

这个工具能把你自己的图片放到 Kindle 上，熄屏的时候显示出来。

用之前只有一件事要先弄好：**Kindle 要能连上电脑**（下面第一节讲）。弄好之后，换屏保就是双击图标、点选图片的事。

---

## 先看这里：我要双击哪个图标？

打开这个文件夹（`kindle-screensaver-tool`），你会看到几个带数字的图标。**只用这几个，其他文件都不要碰。**

| 图标 | 什么时候用 | 怎么用 |
|---|---|---|
| **1-一键安装.bat** | 第一次用，必须先做一次 | 双击它，等它跑完 |
| **2-打开工具.bat** | 装好之后，想用菜单换屏保 | 双击它 |
| **3-拖图片到这里加屏保.bat** | 加新图片，最省事 | 把图片拖到它上面 |
| **4-检查Kindle.bat** | 连不上、或不确定设备好不好 | 双击它 |
| **5-恢复备份.bat** | 换完不满意，想换回来 | 双击它 |

最省事的路线：**第一次双击 1 安装 → 以后把图片拖到 3 上加屏保**。这个版本只用上面这些 bat，不需要懂命令行。

---

## 第一节：开始之前（只需弄一次）

这一步是唯一的门槛。工具要连到 Kindle 才能放图，所以 Kindle 得先满足三个条件。

### 1. Kindle 已经"越狱"并开了 SSH

说人话：Kindle 出厂时不让你随便改里面的东西，需要有人先帮你"解锁"（这叫越狱），再打开一个叫 SSH 的通道，电脑才能连进去放图。

这一步**这个工具帮不了你**，得找懂 Kindle 的人或用现成教程弄好。弄好之后你只需要记住：设备 IP 是多少、私钥文件放在哪。如果已经有人帮你装好了，直接跳过这条。

### 2. Kindle 和电脑在同一个 Wi-Fi

看 Kindle 设置里的 Wi-Fi 名字，和电脑连的 Wi-Fi 名字要一样。不一样就连不上。

### 3. 换屏保前，先按一下 Kindle 的电源键

Kindle 睡觉的时候电脑找不到它。按一下电源键把屏幕点亮，等半分钟再操作。

> 想先确认设备正不正常？双击 **4-检查Kindle.bat**。窗口里能看到"屏幕"后面有数字（比如 1072x1448），就说明设备连上了。

---

## 第二节：第一次使用（只做一次）

双击 **1-一键安装.bat**。

窗口里会显示它在装什么。看到"装好了"就成功了，关掉窗口。

如果看到红色的"安装没成功"，把这个窗口拍下来找人帮忙。常见原因是电脑上没装 Python——这个也需要别人帮你装一次。

装好之后，工具会固定在电脑里，以后不用再装。

---

## 第三节：换屏保（以后就做这个）

### 方法 A：把图片拖进去（最省事）

1. 按一下 Kindle 电源键，等半分钟。
2. 在电脑上找到你想用的图片（一般在"图片"文件夹或桌面）。
3. 用鼠标**按住**图片，拖到 **3-拖图片到这里加屏保.bat** 上面，松开鼠标。
4. 窗口会问"确认添加吗"，输入 `y`，按回车。
5. 等它跑完。下次 Kindle 熄屏，就是新图了。

一次想加好几张？一起选中几张图片，一起拖过去就行。

### 方法 B：用菜单（能看图、删图、换图）

双击 **2-打开工具.bat**，会出现这样的菜单：

```
你想做什么？输入前面的数字，然后按回车：
  1  看看现在有哪些屏保，每张是几号
  2  加新图片（会让你用鼠标选文件，不用打字输路径）
  3  删掉某几张
  4  用新图片换掉某一张
  5  只列出屏保文件名
  6  检查 Kindle 连得正不正常
```

按你要做的输入数字，回车。跟着窗口里的提示走就行：

- **选图片**：会弹出一个选文件的窗口，用鼠标点选，不用打字。
- **问"确认吗"**：输入 `y` 再回车就是同意；直接回车是取消。
- **删图**：它会先列出有哪些图，问你要删第几张。不知道哪张是哪张，就先选 1 看图。
- **换图**：会先给你看一眼新图的效果，问你满意不满意，满意就按 `y`。

## 第四节：出问题了怎么办

| 看到什么 | 怎么回事 | 怎么办 |
|---|---|---|
| 没有找到 Kindle | 设备没醒，或 Wi-Fi 不一样 | 按一下电源键等半分钟；确认 Wi-Fi 名字一样；再双击 4 号检查 |
| 没找到 Python / 安装没成功 | 电脑上没装 Python | 找懂电脑的人装一次 Python 3 |
| 转换失败 / 找不到文件 | 图片路径不对 | 别自己打字输路径，用方法 A 拖进去，或方法 B 弹窗选 |
| 熄屏后是黑屏，没有图 | 图片尺寸不对 | 双击 2，选 6 检查，看"屏幕"后面的尺寸；把这个数字告诉帮你弄设备的人 |
| 换完不满意 | 想恢复原来的 | 双击 **5-恢复备份.bat** |
| 杀毒软件报"木马" | 杀软误会了 | 这是误报，选"允许"。如果选不了，找人帮忙 |

窗口里只要出现看不懂的英文或红字，**把整个窗口拍下来**发给懂电脑的人，比自己猜快得多。

## 第五节：几个词是什么意思

| 词 | 意思 |
|---|---|
| SSH | 电脑连进 Kindle 的一把"门"，要先用它才能放图 |
| 越狱 | 解开 Kindle 的限制，才能装 SSH 和换系统屏保 |
| 私钥 | 开门用的钥匙文件，一般在 `Documents` 旁边的 `.ssh` 文件夹里 |
| 屏保编号 | 每张图有个号（00、01、02…），删图换图时说的"第几张"就是这个号 |
| 路线 A / B | 图放在 Kindle 的哪个位置。不用管，工具会自己认 |
| 体检（kss conn） | 检查一下 Kindle 连没连上、是什么型号、屏幕多大 |

## 给懂电脑的人：命令行用法

安装时会在 PowerShell 里加一个 `kss` 命令。会敲命令的话可以：

```
kss                          菜单
kss add C:\pic.jpg           加图
kss ls                       列出
kss preview                  看图认编号
kss rm 5                     删第 5 张
kss set C:\pic.jpg 3         换掉第 3 张
kss conn                     体检
kss rollback                 恢复备份
kss add C:\pic.jpg -WhatIf   只预览不改设备
```

机型/尺寸自动认；认不出时可以 `-Model pw5` 或 `-Size 1264x1680` 指定。路线 A 是系统目录（需 root），路线 B 是 MobileRead hack 目录，`-Route B` 指定。广告版会提示系统广告可能盖住自定义图。

尺寸表在 `kss-devices.ps1`。设备端 `kss-agent.sh` 要留在 Kindle 的 `/mnt/us/`，别删。
